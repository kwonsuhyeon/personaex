## 2.1 전통적 설명: 벤다이어그램과 변량의 부분제거 {#c2-venn}

회귀분석 수업에서는 통제를 벤다이어그램으로 설명한다. 변수 하나를 통제하면 그 변수와 겹치는 분산이 빠지고 나머지로 효과를 추정한다. 이것을 <dfn>변량의 부분제거</dfn>(partial out)라고 부른다 (p.79-80).

논문의 예시는 지능신념 X(노력하면 지능이 바뀐다는 믿음)가 글쓰기 수행력 Y에 주는 영향이고, 통제변수 후보는 성별 C다. 성별을 통제하면 X와 Y가 겹치는 영역 가운데 성별과도 겹치는 부분이 빠진다 (p.80).

:::box note 노트의 "?" ① — 상관 0.6이면 왜 64%인가 (p.80)
이 대목은 저자들의 주장이 아니라, 비판하려고 소개한 전통적 설명이다 (Breaugh, 2008 재인용).

- **36%와 64%.** 상관 0.6을 제곱한 0.36은 X의 분산 가운데 C로 설명되는 몫이다. 나머지 64%는 C와 무관한 X만의 몫이다.
- **통제의 계산.** C를 통제한 다중회귀는 X의 분산 가운데 이 64% 부분만 써서 X의 계수를 구한다. X에서 C로 설명되는 부분을 빼고(잔차), 남은 부분과 Y의 관계를 보는 것이다 (0.1의 FWL(Frisch-Waugh-Lovell) 정리).
- **전통적 결론.** 통제 전의 X(100%)와 통제 후의 X(64%)는 다른 정보이므로 두 추정치의 크기와 방향은 얼마든지 다를 수 있다.
- **빠진 질문.** 그렇다면 둘 중 어느 쪽이 맞는가? 빠진 36%가 가짜 관련성이었다면 통제한 쪽이 맞고, X의 진짜 효과 일부였다면 통제하지 않은 쪽이 맞다. 벤다이어그램은 이 둘을 구별하지 못한다. 저자들이 인과 그래프로 넘어가는 이유다.

같은 숫자에서 정답이 갈리는 계산 예는 <a href="#k3">핵심 3</a>에 있다.
:::

전통 문헌은 이 그림 위에서 통제변수를 몇 가지 유형으로 나눴다 (p.82-83).

| 전통 용어 | 원문이 인용한 정의 | 통제 여부(전통 문헌) | 쪽 |
|---|---|---|---|
| <dfn>가외변수</dfn>(extraneous variable) | "독립변인 이외에 종속변인에 영향을 미칠 수 있는 연구자가 의도하지 않은 변인"(김석우 외, 2015). 공변량(covariates)·교란변수(confounding variables)·장애변수(nuisance variables)라고도 부른다(Atinc et al., 2012) | 통제한다 | 82 |
| <dfn>무력한 통제변수</dfn>(impotent control variable) | 종속변수와 거의 또는 전혀 상관이 없는 변수 | 통제하지 않는다 (표준오차만 커짐) | 82 |
| <dfn>억제변수</dfn>(suppressor variable) | 종속변수와 관련이 없거나 약하지만, 넣으면 독립변수의 효과와 설명력을 높이는 변수 | 통제한다 (선행연구로 뒷받침될 때) | 82-83 |

세 유형 모두 **종속변수와 얼마나 관련 있는가**를 기준으로 나눈다. 그러다 보니 억제변수처럼 종속변수와 상관이 없는데도 통제해야 한다는 예외가 생긴다. "개념적으로 의미 있는 변수를 통제하라", "의심스러우면 빼라"(Becker et al., 2016, p.158) 같은 지침도 무엇이 의미 있는지는 말해 주지 않는다 (p.81-82).

:::box warn 용어 혼동 두 가지
- **가외변수 ≠ 외생변수.** 국내 문헌 일부는 extraneous variable을 "외생변수"로 번역한다. <dfn>외생변수</dfn>(exogenous variable)는 모형의 오차항과 상관이 없는 변수, 또는 구조모형 안에서 원인을 갖지 않는 변수다(Wooldridge; Kline; Pearl). 가외변수와 전혀 다른 개념이다 (p.83, 주1).
- **"교란변수"의 두 가지 쓰임.** 전통 문헌에서 교란변수는 가외변수의 다른 이름일 뿐이다(종속변수에 영향을 주는 변수). 인과 그래프에서 교란변수는 **처치와 결과의 공통 원인**으로 좁혀 정의된다(2.2절). 같은 단어라도 어느 쪽 정의로 쓰였는지 확인해야 한다.
:::

## 2.2 경로와 세 가지 기본 구조 {#c2-paths}

인과 그래프는 변수 사이의 인과 구조, 곧 <dfn>자료 생성 과정</dfn>(data generating process)을 그린 것이다. Wright(1921)의 경로분석에 뿌리를 둔다 (p.84). 그래프에서 두 변수를 잇는 화살표의 연쇄를 <dfn>경로</dfn>(path)라고 한다. 경로를 따라갈 때 화살표 방향은 따지지 않는다.

정계룡·김용남(2026)의 정의는 다음과 같다 (p.84).

- <dfn>인과적 경로</dfn>(causal path) — 모든 화살표가 원인변수에서 결과변수 쪽을 향하는 경로.
- <dfn>비인과적 경로</dfn>(non-causal path) — 원인변수 쪽을 향하는 화살표가 하나라도 있는 경로. 원인변수로 **들어오는** 화살표로 시작하는 비인과적 경로를 특히 <dfn>뒷문 경로</dfn>(backdoor path)라고 부른다(Pearl, 2009; Neal, 2020).
- <dfn>교란</dfn>(confounding) — 비인과적 경로를 따라 생기는 관련성. 원인변수 효과의 추정치를 편향시킨다. <dfn>가짜 관련성</dfn>(spurious association)이라고도 한다.
- <dfn>열린 경로</dfn>(open path) — 관련성이 흐르는 경로. 막히는 조건은 아래 세 구조로 정해진다.

경로 위의 가운데 변수 하나만 보면 경우는 세 가지뿐이다. 블로그 가짜연구소 Ch3도 같은 세 구조로 설명한다(Chains · Forks · Immoralities).

| 구조 | 모양 | 가운데 변수의 이름 | 통제하지 않으면 | 통제하면 |
|---|---|---|---|---|
| 사슬(chain) | X → M → Y | <dfn>매개변수</dfn>(mediator) | 열림 | 막힘 |
| 분기(fork) | X ← C → Y | <dfn>교란변수</dfn>(confounder) — 처치와 결과의 공통 원인 | 열림 | 막힘 |
| 충돌(collider) | X → C ← Y | <dfn>충돌변수</dfn>(collider) — 두 화살표 머리가 만나는 변수 | **막힘** | **열림** |

충돌변수만 반대로 움직인다. 충돌변수의 **후손**(그 변수의 결과)을 통제해도 경로가 열린다. 이 규칙 묶음을 <dfn>d-분리</dfn>(d-separation)라고 한다. 경로 위에 막힌 지점이 하나라도 있으면 그 경로는 막힌 것이고, X와 Y 사이 모든 경로가 막히면 X와 Y는 d-분리되었다고 한다(Pearl, 2009).

아래 위젯에서 노드를 눌러 직접 확인한다. 초록 화살표는 열린 인과 경로, 빨간 화살표는 열린 비인과 경로, 회색은 막힌 경로다.

## 2.3 뒷문 기준(back-door criterion): 통제는 비인과 경로를 막는 절차 {#c2-backdoor}

인과 그래프 관점에서 <dfn>통계적 통제</dfn>는 원인변수와 결과변수를 잇는 비인과적 경로를 막는 절차다 (p.84). 통제는 그 변수의 특정 값으로 자료를 <dfn>조건화</dfn>(conditioning)하는 것이고, 어떤 변수를 통제해야 하는지는 그래프가 정한다 (p.85).

그 판정 규칙이 <dfn>뒷문 기준</dfn>(backdoor criterion)이다(Pearl, 2009). 교정 기준(adjustment criterion; Shpitser et al., 2010)이라고도 한다 (p.86). 통제 변수 집합 W가 다음 두 조건을 만족하면 X가 Y에 주는 효과를 추정할 수 있다.

1. W 안에 X의 후손(X의 결과로 생기는 변수)이 없다.
2. W가 X와 Y 사이의 모든 뒷문 경로를 막는다.

:::box note 원문 정의 (Pearl, 2009, Definition 3.3.1, p.79 / PDF p.101)
> A set of variables Z satisfies the **back-door criterion** relative to an ordered pair of variables (Xᵢ, Xⱼ) in a DAG G if:
>
> (i) no node in Z is a descendant of Xᵢ; and
>
> (ii) Z blocks every path between Xᵢ and Xⱼ that contains an arrow into Xᵢ.

변수 집합 Z가 DAG G의 순서쌍 (Xᵢ, Xⱼ)에 대해 다음을 만족하면 뒷문 기준을 충족한다. (i) Z의 어떤 노드도 Xᵢ의 후손이 아니다. (ii) Z는 Xᵢ와 Xⱼ 사이의 경로 가운데 Xᵢ로 들어오는 화살표를 포함한 경로를 모두 막는다. 원문의 Z·Xᵢ·Xⱼ가 이 자료의 W·X·Y다.

> The name "back-door" echoes condition (ii), which requires that only paths with arrows pointing at Xᵢ be blocked; these paths can be viewed as entering Xᵢ through the back door.

이름의 유래도 원문에 있다. 조건 (ii)가 막으라는 경로는 Xᵢ를 가리키는 화살표가 있는 경로뿐이고, 이 경로들은 Xᵢ에 뒷문으로 들어오는 길로 볼 수 있다. 그래서 "뒷문"이다. Neal(2020, PDF p.46)은 붙여 써서 backdoor criterion으로 표기한다.
:::

:::box note 총효과와 직접효과 (주3)
그림 3에서 X → C → Y는 성별을 거치는 간접효과다. 관심이 <dfn>총효과</dfn>(total effect)라면 이 경로를 막으면 안 된다. 관심이 간접효과를 뺀 <dfn>직접효과</dfn>(direct effect)라면 성별을 통제해 X → C → Y를 막는다(김용남·인효연, 2024). 무엇을 추정할지 먼저 정해야 통제 여부도 정해진다.
:::

## 2.4 전통 변수 유형을 그래프로 다시 읽기 {#c2-retype}

이제 질문 2에 답한다. 2.1절의 전통 유형과 그 밖에 논문에 나오는 변수 이름을 그래프 위치로 옮기면 다음과 같다.

| 변수 이름 | 원문 정의(요지) | 그래프에서의 위치 | 통제할까? | 쪽 |
|---|---|---|---|---|
| 가외변수 | 종속변수에 영향을 주는 의도하지 않은 변수 | C → Y. 여기에 C → X도 있으면 교란변수, 없으면 Y의 원인일 뿐 | C → X가 있을 때만 통제한다. C → X가 없으면 빼도 편향이 생기지 않는다 | 82, 86-87 |
| 공변량·장애변수 | 가외변수의 다른 이름(Atinc et al., 2012) | 이름만으로는 위치를 알 수 없다 | 위치를 그려 보고 판단한다 | 82 |
| 교란변수(인과 그래프 정의) | 처치와 결과의 공통 원인 | X ← C → Y (분기) | 통제한다 | 84-85 |
| 무력한 통제변수 | 종속변수와 상관이 없는 변수 | Y와 직접 연결되지 않음 | 필요 없다. 다만 Z → X만 있는 위치라면 통제 시 편향 증폭 (2.5절) | 87-88 |
| 억제변수 | Y와 상관이 약한데 넣으면 X의 계수와 설명력이 커지는 변수 | 그림 4(a)의 Z가 전통 기준으로는 억제변수처럼 보일 수 있다 | 계수가 커졌다고 좋은 것이 아니다. 편향이 커진 것일 수 있다 | 88 |
| 매개변수 | X의 결과이면서 Y의 원인 | X → M → Y (사슬) | 총효과가 관심이면 통제하지 않는다 | 85, 주3 |
| 충돌변수 | 경로 위에서 두 화살표 머리가 만나는 변수 | X → C ← Y, 또는 U₁ → C ← U₂ | 통제하지 않는다 (막힌 경로가 열림) | 89-91 |
| <dfn>처치 이후 변수</dfn>(post-treatment variable) | 원인변수 이후에 측정된 변수 | X의 후손 | 통제하지 않는다 (뒷문 기준 조건 1) | 90 |
| <dfn>배경변수</dfn> / 처치 전 변수 | 원인변수 이전에 존재하는 변수 | 교란변수일 수도, 편향 증폭 변수(Z)일 수도, 충돌변수(M-bias의 C)일 수도 있다 | "배경변수는 모두 통제하라"는 틀릴 수 있다 | 89, 91 |
| 외생변수 | 모형 안에서 원인을 갖지 않는 변수 | 들어오는 화살표가 없는 노드 | 통제 유형이 아니다. 외생 여부와 통제 여부는 따로 판단한다 | 83 |

:::box answer 질문 2의 답
변수의 **이름**이 아니라 그래프에서의 **위치**가 통제 여부를 정한다. 전통 유형은 종속변수와의 관련성으로 나눴기 때문에 같은 이름 안에 통제해야 할 변수와 통제하면 안 되는 변수가 섞여 있었다. 인과 그래프를 그리면 규칙은 하나로 줄어든다. "비인과적 경로를 막는 변수만 통제한다. X의 후손은 통제하지 않는다." 저자들도 이렇게 하면 모호한 유형 구분이 필요 없어진다고 말한다 (p.87).
:::

:::box note 노트의 "?" ② — "독립변수와 무관하고 종속변수와만 상관있는 변수를 빼면 편의가 생긴다"는 말은 왜 틀릴 수 있나 (p.87)
C → Y만 있고 C → X가 없으면 X로 들어오는 화살표가 없다. 비인과 경로가 없으니 C를 빼도 X 효과의 추정치는 편향되지 않는다. 그래서 "독립변수와 관련성은 없지만 종속변수와는 상관이 있는 변수를 생략하면 편의가 생긴다"는 설명(박원우 외, 2010, p.16)은 그래프로 확인하지 않으면 틀릴 수 있다 (p.87). 정밀도(표준오차)로 보면 Y의 원인을 넣는 편이 유리할 수 있다. 다만 원문은 이 부분을 다루지 않는다. {{보충}}
:::

## 2.5 통제하면 오히려 나빠지는 경우 {#c2-harm}

통제변수를 넣어서 편향이 생기거나 커지는 경우가 두 가지 있다. 전통적 설명으로는 보이지 않지만 인과 그래프를 그리면 드러난다 (p.87-91). 노트의 "?" ③(Ⅳ장)에 대한 답이기도 하다.

### 편향 증폭 {#c2-amp}

그림 4(a)에서 Z는 X에만 영향을 주고 Y에는 직접 영향을 주지 않는다. 교란변수 C가 X와 Y를 함께 움직이는데, 논문이 세우는 회귀식 `Y = a + b₁X + b₂Z + ε`에는 C가 없다 (p.88). X → Y는 없으니 참 효과는 0이다.

:::dag biasamp

논문은 이 구조를 선형 구조방정식으로 쓴다 (p.88). 모든 변수는 표준화되어 있고 ε는 서로 독립인 오차항이다.

```
Z = εZ
C = εC
X = αC + γZ + εX
Y = βC + εY
```

- Z를 통제하지 않을 때 X의 회귀계수: `b₁ = αβ` — C 때문에 생긴 <dfn>초기편향</dfn> (p.89)
- Z를 통제할 때: `b₁ = αβ / (1 − γ²)` (p.88)

분모 `1 − γ²`가 <dfn>편향 증폭 요인</dfn>(bias amplification factor; Steiner & Kim, 2016)이다. 표준화했으므로 0 < 1 − γ² < 1이고, 편향은 언제나 커진다 (p.89). 예를 들어 γ = 0.6이면 편향이 1/0.64 ≈ 1.56배가 된다(직접 계산한 예). 이 현상을 <dfn>편향 증폭</dfn>(bias amplification)이라고 한다(Pearl, 2010; Steiner & Kim, 2016).

이유를 말로 풀면 이렇다. Z를 통제하면 X의 변동 가운데 Z가 만든 부분, 곧 교란과 무관한 부분이 빠진다. 남은 변동에서 C가 만든 부분의 비중이 커진다. {{보충}}

그림 4(a)의 계수는 γ가 Z → X, α가 C → X, β가 C → Y다 (p.87). 증폭 요인에 들어가는 것은 γ다.

Z의 위치는 3장에서 볼 <dfn>도구변수</dfn>(instrumental variable)와 같다. 도구변수는 통제변수로 넣지 않고 다른 방식으로 쓴다.

### 충돌변수 편향 {#c2-collider}

그림 4(b)는 X → C ← Y다. X와 Y는 서로 독립이다(`Cov(X, Y) = 0`). C를 통제하면 FWL(Frisch-Waugh-Lovell) 정리에 따라 잔차끼리의 공분산이 `Cov(X̃, Ỹ) = −αβ`가 된다 (p.90). 없던 관련성이 생기고, 연구자는 이것을 X의 효과로 잘못 읽을 수 있다. 위의 충돌 위젯에서 C나 D를 눌러 보면 같은 현상이 나타난다.

처치 이후 변수를 통제하지 말라는 교육을 받은 연구자는 이 경우를 피한다. 그런데 그림 4(c)처럼 **처치 전** 변수도 충돌변수일 수 있다 (p.90-91). 모양이 M자를 닮아 흔히 M-bias라고 부른다. {{보충}}

:::dag mbias

:::box warn "원인변수 이전의 배경변수는 모두 통제하라"
그림 4(a)의 Z와 그림 4(c)의 C는 둘 다 원인변수 이전의 배경변수다. 하나는 편향을 키우고, 하나는 없던 편향을 만든다. 그래프 없이 내리는 개념적 수준의 지침은 이 두 문제를 일으킬 수 있다 (p.89, 91).
:::

논문은 적용 사례로 곽나람·이상윤·김용남(2024)을 소개한다. 교사의 자녀 유무가 직무만족도와 소진에 주는 영향을 분석하면서 인과 그래프를 먼저 그린 뒤 편향 증폭과 충돌변수 편향을 일으킬 변수를 빼고 통제변수를 골랐다. 이 절차는 자료 수집 전에 사전등록되어 있다([OSF](https://osf.io/q2j5r/), p.91).

## 2.6 종합 연습 {#c2-practice}

변수 이름을 지운 그래프다. Z, C, M, K가 각각 무엇인지 먼저 말해 보고, 노드를 눌러 맞는 통제 집합을 찾는다.

:::dag practice

:::box note 풀이 (먼저 풀어 보고 펼쳐 볼 것)
<details><summary>펼치기</summary>Z는 X에만 영향을 주는 도구변수 위치, C는 교란변수, M은 매개변수, K는 충돌변수다. {C}만 통제하면 뒷문 기준을 충족한다. {C, Z}도 경로 판정으로는 충족하지만 선형 모형에서 Z를 함께 넣으면 정밀도가 떨어진다. 이 그래프에는 측정 못 한 교란이 없으므로 편향 증폭은 생기지 않는다. {{보충}} M이나 K를 넣으면 X의 후손을 통제한 것이 되어 판정이 실패한다.</details>
:::
