# Nemotron-Personas-Korea 학습 노트

NVIDIA가 공개한 한국형 합성 페르소나 데이터를 공부하며 정리한 문서 모음이다.

- 사이트: https://kwonsuhyeon.github.io/personaex/
- 1차시 자료: https://kwonsuhyeon.github.io/-statistics/

## 문서

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 페이지 |
| `report.html` | Nemotron-Personas-Korea 이해 보고서 |
| `us-person-pgm.html` | SDG-PGMs 미국 예제(us_person) 읽기 |
| `beginner.html` | 입문 실습: 표본으로 시작하기 (pandas, 내려받기 없음) |
| `quickstart.html` | 실습: 불러오기, 기초통계, 직무별로 보기 (polars, 전체 데이터) |
| `python-basics.html` | 실습 노트북에 나온 Python 기초 문법 |
| `notebooks/00_beginner.ipynb`, `notebooks/01_hf_quickstart.ipynb` | 노트북 원본 |
| `data/sample_random.parquet`, `data/sample_jobs.parquet` | 입문 실습용 표본. 규칙은 `data/README.md` |

## 출처와 라이선스

- 데이터: [NVIDIA Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea) (Hugging Face 버전, CC BY 4.0). 문서에 실린 페르소나 예시는 이 데이터의 원문이고, 등장하는 인물은 모두 합성된 가상 인물이다.
- 미국 예제: [NVIDIA-NeMo/SDG-PGMs](https://github.com/NVIDIA-NeMo/SDG-PGMs) (Apache 2.0).
- NGC 확장 버전의 원문은 싣지 않았다.
